# التقرير العلمي لمشروع التخرج: نظام ذكي لاكتشاف هجمات وثغرات الويب عبر تحليل طلبات HTTP
**AI-Powered Web Vulnerability & Attack Detection via HTTP Request Analysis (Smart WAF)**

*(نسخة محفوظة داخل مجلد المشروع للرجوع إليها أو تحويلها إلى Word/PDF)*

انظر التقرير الكامل المرفق في مستند التخرج التفاعلي (Artifact) والذي يتضمن:
1. الملخص التنفيذي (Abstract)
2. الفصل الأول: المقدمة ومشكلة البحث وأهداف المشروع
3. الفصل الثاني: الإطار النظري وجدول المقارنة مع الدراسات السابقة (Rule-Based WAF vs Word TF-IDF vs Hybrid Char N-Grams + Deep MLP)
4. الفصل الثالث: المنهجية والمعمارية المقترحة (مع مخطط `Mermaid Flowchart` والمعادلات الرياضية لـ Shannon Entropy و TF-IDF)
5. الفصل الرابع: التنفيذ العملي ومخطط تتابع الفحص اللحظي (`Sequence Diagram`)
6. الفصل الخامس: النتائج التجريبية ومناقشتها (جداول الدقة وزمن الاستجابة بالملي ثانية)
7. الفصل السادس: الخاتمة والتوصيات المستقبلية
